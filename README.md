# HTC 2026 Driver Guide

Offline installable web app for the Hood To Coast 2026 relay (Driver Edition).
All 36 legs with turn-by-turn directions & GPS, race rules, safety, checklists, a live race clock, and Seaside parking.

**Install on iPhone:** open the site in **Safari**, then Share → **Add to Home Screen**. After one load it works fully offline (no cell service needed).

Built from the official HTC 2026 Driver Handbook. Unofficial personal reference — verify against the official handbook/app before race day.
